## Autonomous closing reports

Reports cover activities, results, recorded insights, errors and unfinished work, excluding private reasoning. Exact tool counts and stop reasons come from durable records. Model-authored observations are labelled separately from verified receipts. An accepted post-stop final is reused instead of sending a duplicate.

A new user steering event restores normal tools and configured reasoning. These settings do not apply to ordinary agent turns and introduce no token or iteration cap.
