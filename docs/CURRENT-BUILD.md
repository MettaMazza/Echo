## Autonomous closing reports

Disabling an enabled autonomous run commits a summary request in the same transaction. A separate tool-free reporter waits for the action worker to finish; it never reactivates a cancelled run. Reports cover activities, results, recorded insights, errors and unfinished work, excluding private reasoning. Exact tool counts and stop reasons come from durable records. Model-authored observations are labelled separately from verified receipts. An accepted post-stop final is reused instead of sending a duplicate.

On the llama.cpp adapter, standalone reports and the next closing response after model `autoOff` use direct reporting without a separate reasoning stream. A new user steering event restores normal tools and configured reasoning. These settings do not apply to ordinary agent turns and introduce no token or iteration cap.

## Compaction and RSI

Source ranges are reviewed against the exact candidate, with digest and contiguous-range validation. Synthesis now carries each semantic verdict, explanation, finding and correction once, rather than repeatedly escaping nested receipts and binding hashes. The 370-source failure case shrank to 52,809 input tokens before the instruction wrapper; its context is 262,144 tokens with an 8,192-token reserve. All 370 review ranges were compared field-for-field against their originals. No repair finding is silently converted to approval.

Blocking compaction is foreground work. Previously it was marked background, which the configured model server pauses while interactive generation runs. Memory work retains its separate scheduling policy. Synthesis uses indexed structured assessments, expanded by the host into the existing exact-source validation contract. Native coverage and acceptance gates still decide whether context may activate.

The RSI implementation includes durable candidate submission, build, pinned acceptance, independent review, protected activation, post-activation health and rollback. Service health, model activity and completed compaction are not evidence of a completed RSI deployment. Run-level completion must be established separately.

## Setup and portability

The [setup toolkit](../tools/setup/README.md) scans hardware, validates packages and verifies an existing macOS deployment before creating a desktop shortcut. It is not yet a finished fresh-machine universal installer. Windows/Linux entry points are experimental; native Darwin-specific APIs still require a proper port and native acceptance. Only macOS has production end-to-end evidence. Do not advertise a complete Windows/Linux application on the strength of installer fixture tests.
