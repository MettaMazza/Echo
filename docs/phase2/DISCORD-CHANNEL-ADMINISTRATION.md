New channels copy the originating channel's explicit permission overwrites. Metadata is released only for the same guild and an exact matching overwrite representation. This is conservative: equivalent but differently represented permission sets can be withheld. Mismatch does not mean absence. Private-channel metadata is not dumped into a public conversation merely because an admin requested it. Parent categories require matching audience, identity, type and permissions. A durable immutable per-run/call mutation claim precedes network transmission. A repeated call cannot replay an uncertain create/edit/delete, including after restart.
