# Scoped JSON selection

Step 08 structured-data operation `workspace_read_json` accepts a workspace `path` and string-array `segments`. Empty segments select the root. Object keys match exactly; array indexes are canonical zero-based decimal strings. Missing paths and traversal through scalar values return explicit statuses.

The full UTF-8 file is parsed and duplicate object keys are rejected, including outside the selected subtree. Returned `json` is a string containing the original selected JSON spelling, preserving large integers, decimal notation and escape sequences. `sha256` hashes the entire observed source; `byte_offset` and `byte_length` locate the selection. The operation reads the full file into memory and does not execute content. Existing authenticated workspace read permissions and descriptor-based path access apply.
