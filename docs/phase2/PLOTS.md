# Workspace plots

Original step 08 computation includes plots. `workspace_plot` creates a new SVG from labelled numeric line/scatter series. Linear axes span the supplied data; line points connect in input order. Multiple series share axes and have a legend. Constant coordinates appear at the axis centre. Decimal/scientific JSON numbers use native binary64 arithmetic; non-finite values and unrepresentable scaling fail explicitly. Coordinates have normal floating-point rounding. Exact input JSON remains in inert SVG metadata, and each point retains its supplied values in a tooltip. This provides a reproducible specification, not an assertion that input measurements are correct.

The tool accepts a relative workspace path and a plot object with title, axis labels, and named series of [x,y] points. It uses the existing atomic, exclusive text publication: existing files are preserved, the result includes SHA256, and a crash can leave a pending stage. Scope and current device membership are checked before publication and again afterward. `attach_file` publishes the result with `image/svg+xml`; the client previews SVG through an image element and verified Blob bytes, never HTML injection or an object/embed element. Generated SVG has escaped text, no scripts, no links and no external resources. Uploaded SVG is likewise displayed only through the image rendering path.

Implementation: `app/workspace/plot_numbers.ep`, `plot_svg.ep`, `app/tools/plot_schema.ep`, workspace dispatch and the existing attachment lifecycle. No plotting service, remote provider, Python application code or compiler modification is involved. The plot uses a fixed drawing layout, with legend height growing with series count; it imposes no sample-count or model-context cap. This is line/scatter plotting, not a claim of every possible chart type or completed computation family.

`test_plot_numbers.ep` verifies native decimal/scientific conversion and non-finite detection. `test_plot_svg.ep` verifies scaling, escaped labels, invalid input, publication digest, no overwrite, outsider denial and revoked-device denial. Native Quick Look rendering was visually inspected. `test_group_plot_workbook.ep` exercises the real streamed shared dispatcher for plotting and existing workbook creation/readback; this caught and corrected missing workbook operation mappings in that shared route. `test_live_plot.ep` checks actual primary-model plot generation and attachment publication, plus the event chain. Private evidence lives under `evidence/phase2/plots-20261016/`; a failed fixture missing its attachment schema is retained rather than counted as a product failure or a passing run. Native preview is not physical-phone/browser interaction acceptance.
