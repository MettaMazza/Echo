# Deliberate memory sharing — Step 09

Sharing is an authenticated human-selection operation, not a model tool. `app/memory/sharing.ep` prepares a canonical preview of one selected original user message, Echo reply or imported source. The preview includes the exact text and text digest, original event and archive digest, original session/scope/kind, confirming principal, destination session/scope/title/channel and destination participant list. Confirmation supplies that preview's digest. The writer transaction rechecks source access and the current destination audience before committing.

A committed share is an independent `source_import` copy in the destination archive. It grants no access to other source records, attachments, private histories or future changes. Originals are unchanged. Copies retain an immediate provenance link, including when a participant deliberately saves a shared copy into their own private silo. A later audience change does not retrospectively erase already confirmed copies; it prevents stale confirmations and does not grant new members access to an earlier audience's archive. Derived assertions from the copy have their ordinary correction and forgetting lifecycle.

`POST /api/memory-share` uses existing exact-origin and bearer authentication. `action: preview` requires `source_event` and `destination`; `action: commit` additionally requires a unique `identity` and `review_digest`. A same-identity/same-selection retry returns the existing receipt. A changed selection conflicts. Model-selected actor or role fields grant no authority. The endpoint is unavailable on restored read-only archives. Browser controls remain part of the original Step 10 UI work; this document does not claim a completed sharing UI.

The native primitive/handler test passed explicit private-to-group and group-to-private copies, exact review binding, foreign-source denial, idempotence, unchanged source digests, provenance, private recall, reopen/archive integrity and audience-change rejection. Run 01 and its result are preserved in `evidence/phase2/memory-sharing-20261017/`. Authenticated HTTP route acceptance passed in run 02: preview and commit returned success; foreign-source and foreign-origin requests were denied. Deployed as `phase2-memory-sharing-20261017-014615`; local HTTP and host-side LAN HTTPS status returned 200. Only the server binary changed, its runtime fingerprint was verified, and the model process remained running. The route fixture initially used an unsupported mixed-type literal list; its configuration now uses the established append-list form, without compiler changes.

Copies retain `original_authorship` through repeated sharing. The private and shared graph validators treat copied Echo-authored text as inference; sharing does not convert it into a user account or observed tool result. Run 03 passed the regression covering a private Echo reply copied into a group and then into another participant’s private library.

## Browser delivery — 17 October 2026

Each saved message now has **Share…** beside Copy. The dialog lists the user's private conversations and writable current shared segments. Open a new shared conversation once before using it as a destination. Review shows the exact source text and principal recipients returned by the server. Confirmation copies only the selected text, preserving its source provenance; attachments, other history and future changes are excluded. The dialog discloses that the independent copy survives departure from the original conversation. Reopening and repeating an unchanged selection reuses its locally saved operation identity.

Reviewed copies appear in destination transcripts as **Shared source**, without impersonating a new user message or Echo response. Transcript pagination includes those records within the existing branch and membership scope. Other source imports are not automatically added to conversation display.

Acceptance: actual Codex browser preview, cancellation with focus restoration, confirmation, reopened repeat (one stored copy), private destination display, current shared destination selection/confirmation/display. Native regression checks include newest-page and prior-page boundaries alongside existing ownership, HTTP-origin, review-digest and audience-change rejection. Evidence is retained privately under `evidence/phase2/share-ui-20261017`; this does not replace physical-phone acceptance or close the remaining Step 10 requirements. Deployed as `phase2-sharing-ui-20261017-020355`; local and LAN health passed, model process unchanged. TTS layout was not edited.
